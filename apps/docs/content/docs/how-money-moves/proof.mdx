## Run them yourself

After [running Tegata yourself](/docs/build/self-host):

| Proof | Command |
| --- | --- |
| A 0-NEAR account moves a token (wNEAR); the operator pays | `pnpm ops proof-relay` |
| Many gas-free actions at once never collide or double-send | `pnpm ops proof-parallel` |
| An action stopped before or after sending lands exactly once | `pnpm --filter @tegata/services exec tsx src/proofs/recover.ts` |
| An invoice sent through the app's own services; pay it in parts with `pnpm ops pay-link <link> <dollars>` | `pnpm --filter @tegata/services exec tsx src/proofs/invoice.ts` |
| A referral: self-referral refused, a funded payer ignored, both rewards paid | `…/proofs/referral.ts setup`, then `pay <link> <dollars>`, then `sweep` |
